# @metodo-a/ui

Libreria componenti riusabili + ecommerce blocks.

## Uso

```tsx
import { Button, ProductCard, MiniCart } from '@metodo-a/ui';
```

- Temi disponibili:
  - `src/styles/theme-default.css`
  - `src/styles/theme-brand-a.css`
